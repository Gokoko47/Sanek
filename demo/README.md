# Pakostnik Demo — автономный пример интерфейса

Отдельное Android-приложение с пакетом `ai.pakostnik.demo`, которое устанавливается рядом с обычным Telegram и будущим полным Pakostnik.

Не нужны Telegram `api_id`/`api_hash`, аккаунт или сервер ИИ. Приложение не запрашивает разрешения на сеть, контакты, микрофон, камеру или файлы. Все сообщения тестовые; введённый текст сохраняется только в данных демоприложения.

## Что проверить

- Список чатов, поиск, переход в переписку и возврат.
- Добавление своего сообщения в локальную переписку.
- Кнопка «+ входящее» добавляет тестовое сообщение.
- Кнопка «✕ удаление» отмечает последнее тестовое входящее крестиком, сохраняя его в чате. Также можно удерживать карточку входящего.
- Переключение ручного режима, помощника и автопилота. Ответы заранее заданы и имитируются локально; к ИИ приложение не обращается.
- Карточки фото, голосового, кружка и документа через кнопку `+` у поля ввода. Реальных записи, воспроизведения, загрузки и отправки медиа здесь нет.
- Вкладки контактов и звонков показывают тестовые данные; настоящие звонки не подключены.
- «Меню → Оформление» или кнопка шестерёнки: фон/акцент RGB, шрифт, размер, скругление, пресеты, предпросмотр и сохранение после перезапуска.
- «Меню → Сбросить тестовые переписки» восстанавливает начальные данные.

## Скачать APK

Откройте GitHub Actions этого репозитория → **Pakostnik Demo APK** → успешный запуск → Artifacts → **pakostnik-demo-apk**. Распакуйте ZIP и установите `app-debug.apk`. Android может попросить разрешить установку из выбранного браузера или файлового менеджера.

Это debug APK для личного теста интерфейса. При смене подписи в следующем запуске CI может потребоваться удалить старую демоверсию перед установкой новой; локальные тестовые сообщения тогда удалятся.

## Сборка

GitHub workflow `.github/workflows/demo.yml` использует JDK 21, Gradle 8.13 и Android SDK 35. Он не скачивает исходники Telegram, TDLib или NDK и не обращается к GitHub Secrets.

Локально с установленными JDK, Gradle и Android SDK:

```bash
gradle -p demo :app:assembleDebug
```

В демо переиспользуется только чистый Java-класс `ConsolePalette` из основного проекта. Весь настоящий Telegram-клиент остаётся отдельным проектом, собираемым через `bootstrap.sh` и основной workflow.
