# Проверки первой версии

Проверено 2 ноября 2026 года:

- Наложение изменений на чистый checkout Telegram `3de37c8cfb039452be7398909461da6288babf15` — успешно.
- `git diff --check` изменённых исходников — успешно.
- XML собственной иконки — корректный.
- YAML GitHub Actions — разбирается без синтаксических ошибок.
- `python3 -m unittest discover -s tests -v` — 19 тестов успешно, включая Java-проверку 12 примеров текстового фильтра.
- Все двенадцать добавленных Java-классов отдельно скомпилированы с Android API 36 и тестовыми сигнатурами используемых классов Telegram. Такая проверка обнаруживает ошибки Java и обращения к Android API, но не заменяет сборку против полного Telegram.

Не проверено:

- Полная компиляция Telegram, нативных библиотек и APK.
- Успешное завершение APK-сборки в GitHub Actions.
- Авторизация и отправка через реальный аккаунт.
- Работа приложения на физическом Android-устройстве.
- Вызов настоящего ИИ-провайдера и круглосуточная фоновая работа.

Причина остановки полной сборки в рабочей среде: подмодуль `https://chromium.googlesource.com/libyuv/libyuv/` заблокирован сетевой политикой, HTTP 403. Обход блокировки не выполнялся. Дополнительно исходный Gradle Wrapper не получил дистрибутив через Java-соединение; официальный архив Gradle скачан через разрешённый адрес downloads.gradle.org, но недоступность libyuv всё равно препятствует полной сборке.

Проект предназначен для следующей стадии: первая облачная сборка, установка и интеграционная проверка на собственном аккаунте в тестовой переписке.

Добавлены проверки шлюза расшифровки: авторизация, тип файла, пустой файл, OGG/MP4 multipart, отказ провайдера и общий лимит. Локальный архив, применение темы и запись/воспроизведение медиа требуют интеграционной проверки на устройстве.

Просмотр архива доступен из меню личной переписки и фильтруется по её ID. Штатные пути отправки фото/видео/документов и сохранения в загрузки/галерею/музыку сохранены. Реальные медиапередачи и переход по пункту меню ещё требуют проверки на устройстве.

Добавлен тест реального фильтра удалений с изолированными адаптерами: сохранение входящего, отметка удаления, неизвестный ID, коллизии ID каналов, обычная группа, исходящее, таймер, одноразовое медиа, защищённое и секретное сообщение, сервисный чат, собственное удаление, выключение, очистка истории, изоляция аккаунтов, повторное создание экземпляра и выход. Перехват удаления проверен в исходниках до UI и очереди удаления из БД. Полная интеграция с базой Telegram и файловым кэшем на устройстве не проверялась.

Проект опубликован в https://github.com/Gokoko47/Sanek . Первый запуск Actions остановился на устаревшем пакете SDK tools; настройка изменена на platform-tools. Повторный запуск https://github.com/Gokoko47/Sanek/actions/runs/41510915237 остановился до компиляции: AssertionError: Add TG_API_ID repository secret. Проверка TG_API_HASH пока не достигнута; для сборки нужны оба собственных параметра в GitHub Secrets. APK не создан.

Добавлено настраиваемое монохромное оформление. Проверены правила RGB, монохромное преобразование с сохранением alpha, контраст, стандартные пресеты и ошибки ввода. Патч темы применяется к исходному парсеру Telegram; сообщения и список чатов используют выбранный шрифт. Сохранение настроек и обновление экранов после смены темы должны пройти проверку в APK. Основные исходные экраны входа, контактов, чатов, звонков, медиа и историй сохранены.
