# Pakostnik Business на Android через Termux

Телефон заменяет отдельный VPS/Railway. Личные Telegram api_id/api_hash не нужны. OpenAI API остаётся отдельной услугой: запуск на телефоне не делает использование ИИ бесплатным.

Код и изолированные проверки готовы. На реальном Android фоновая работа, Business-подключение и доставка ответов ещё не проверены.

## Установка

Установите [Termux из F-Droid](https://f-droid.org/packages/com.termux/). Откройте Termux и выполните:

```bash
pkg update -y
pkg install -y python git
cd ~
git clone https://github.com/Gokoko47/Sanek.git
cd Sanek
python -m business.phone setup
```

Если проект уже скачан, при остановленном боте выполните git pull --ff-only из каталога Sanek вместо повторного clone.

В мастере вставьте токен своего бота от BotFather: ввод скрытый. Для первого запуска оставьте ID=0 (Enter). Стиль можно оставить по умолчанию. Ключ OpenAI при ID=0 не нужен.

У бота включите Business Mode через /mybots → Bot Settings в официальном BotFather. Токен вводится только в мастер Termux, не в этот чат и не в сообщения боту.

## Получить ID и включить автоответы

Запустите из папки проекта:

```bash
python -m business.phone run
```

В Telegram отправьте своему боту /id. Он покажет ваш числовой Telegram ID.

Вернитесь в Termux, остановите процесс Ctrl+C и дождитесь завершения (долгий запрос может завершаться около минуты). Повторите:

```bash
python -m business.phone setup
```

Токен оставьте прежним (Enter). Укажите полученный ID и ключ OpenAI API скрытым вводом. При ненулевом ID ключ ИИ обязателен; подписка ChatGPT не заменяет его.

Снова выполните python -m business.phone run. В Telegram откройте Настройки → Telegram Business → Чат-боты, подключите своего бота, выберите переписки и разрешите ответы. Проверьте новым текстовым сообщением с другого аккаунта после запуска.

Команды в личке бота: /status, /pause, /resume, /style, /example, /examples, /clearstyle. Например:

```text
/style коротко, на ты, с маленькой буквы, без официоза
/example как дела? => да норм, ты как
```

## Фоновая работа

Разрешите Termux уведомления и фоновую работу. В настройках батареи Android выберите для Termux «Без ограничений» или аналогичный пункт производителя. Termux можно свернуть, но не завершайте его сессию и не используйте принудительную остановку.

При запуске используется termux-wake-lock, если команда доступна; при обычном завершении блокировка освобождается. Это помогает при выключенном экране, но не отменяет ограничений Android. Нужны интернет, заряд и работающий процесс. При выгрузке приложения, выключении телефона или недоступной сети ответы могут прерваться.

По умолчанию после перезагрузки запустите бота снова вручную. Один токен должен использовать один polling-процесс: не запускайте его одновременно на телефоне и отдельном сервере.

## Необязательно: автозапуск

Установите [Termux:Boot из F-Droid](https://f-droid.org/packages/com.termux.boot/) из совместимого с Termux источника и откройте дополнение один раз. После проверки ручного запуска можно создать стартовый скрипт:

```bash
mkdir -p ~/.termux/boot
cat > ~/.termux/boot/pakostnik <<'EOF'
#!/data/data/com.termux/files/usr/bin/bash
sleep 15
cd "$HOME/Sanek"
exec bash business/termux-start.sh
EOF
chmod 700 ~/.termux/boot/pakostnik
```

Автозапуск зависит от Android, разрешений производителя, сети и первого разблокирования устройства. Он не проверялся на телефоне в этой среде. Если процесс не запустился, откройте Termux и выполните ручной запуск из папки проекта.

## Данные

Токены и параметры: ~/.config/pakostnik-business/config.json, права файла 600 и папки 700. Состояние и образцы стиля: ~/.local/share/pakostnik-business/state.sqlite3. Они находятся в закрытом хранилище Termux, вне репозитория и /sdcard. Это приватные файлы приложения, не отдельное шифрованное хранилище.

Токены не включаются в команду запуска, shell history, вывод мастера или журналы бота. Самостоятельно не вставляйте их в исходники и команды.

Показать только пути: python -m business.phone paths.
Удалить локальный файл токенов с подтверждением: python -m business.phone forget.
Удаление файла не отзывает токен в BotFather и не удаляет образцы в SQLite. Для образцов используйте /clearstyle перед остановкой. Удаление приложения или данных Termux удалит локальную конфигурацию и состояние.

Это текстовый Business-бот, а не Android-форк Telegram: установка Termux не меняет дизайн официального клиента и не добавляет крестики удалённых сообщений. Остальные возможности и ограничения — в [README.md](README.md).
